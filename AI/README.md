# The knowledge base of Forge.Next.Security

For AI sessions (and people) who continue the work on this package. `CLAUDE.md` in the repository root holds the rules;
this folder holds the background, so a new session does not have to rediscover it.

| File | What is in it | Update it when |
| --- | --- | --- |
| `HISTORY.md` | How the package evolved, what Zoltán asked for and decided, in order, with the reasons | Zoltán decides something, or asks for a change |
| `DESIGN.md` | How the package is built: the parts, the targets and their dependencies, the AES payload, the certificate profile, and why each design choice was made | The code's structure, the targets or the behaviour change |
| `VERIFICATION.md` | How to check the package (build, tests, the package contents, the Linux run, the probe of the README's statements), and what was run when, with the results | A check is run or a new one is added |
| `OPEN.md` | What is not done or not verified yet, the findings, and the questions waiting for Zoltán | An item is closed or a new one comes up |

Keep the files short and factual. Dates are absolute (2026-11-11, not "today"). Write in English.
